# Color Reference — From the Front-end Book

## Core Rules (Taste Skill)
- **No pure #000000** — use off-black (zinc-950, near-black warm gray)
- **No pure #ffffff** — use off-white
- **Max 1 accent color**, saturation < 80%
- **One palette per project** — don't mix warm/cool grays
- **No AI purple/blue glow** by default (The Lila Rule)

---

## Dark Mode Palette (Taste Skill Default)
| Role | Hex | Description |
|------|-----|-------------|
| Background | `#0c0c0c` | Off-black base |
| Surface | `#1a1a1a` | Card/sidebar surface |
| Elevated | `#242424` | Hover/dropdown surfaces |

| Text Primary | `#f5f5f5` | Off-white body text |
| Text Secondary | `#a0a0a0` | Muted body text |
| Text Tertiary | `#6b6b6b` | Labels, metadata |
