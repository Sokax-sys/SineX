## GitHub's Design Language (Deep Analysis)

Source: `Chapter 2 - Popular style/github-design-md.md` — A 3,291-line AI/LLM-driven design extraction of github.com (May 2026, 1,930 elements analyzed).

### Key Findings

**Color**: 37 unique colors, `#f0f6fc` (644 uses) and `#ffffff` (1450 uses) most common. 13 unique gradients. 900+ CSS custom properties for colors alone.

**Typography**: Mona Sans (1261 elements), 10 sizes from 64px to 12px. 9 font weights in use (recommendation: standardize to 3).

**Spacing**: 2px base unit, tokens from `spacing-1` (1px) to `spacing-432` (432px).

**Layout**: 65 grid containers, 284 flex containers. Container widths: 924px-1280px. Grid columns: 1-col (19x), 2-col (17x), 12-col (9x).

**Accessibility**: 100% WCAG 2.1 score — 6 passing, 0 failing color pairs. Highest ratio: `#25292e`/`#f6f8fa` (13.74:1 AAA).

**Design System Score: 82/100 (Grade B)**:
- Color Discipline: 80/100
- Typography Consistency: 65/100
- Spacing System: 100/100
- Accessibility: 100/100
- CSS Tokenization: 100/100

**Issues**: 4,320 `!important` rules, 81% CSS unused, 32,695 duplicate declarations.

**Z-Index**: 4 layers — modal (1000+), dropdown (100-999), sticky (32-99), base (-1 to 3).

This analysis methodology (AI extraction of CSS variables, tokens, component patterns, accessibility scores) can be applied to any website for reverse-engineering their design language.
