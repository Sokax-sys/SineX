## Core Philosophy (read this first)

```
BRIEF INFERENCE → 3 DIALS → DESIGN SYSTEM MAP → BUILD → PRE-FLIGHT CHECK
```

**The 3 Dial:**
- `DESIGN_VARIANCE` (1-10): symmetry vs. chaos
- `MOTION_INTENSITY` (1-10): static vs. cinematic
- `VISUAL_DENSITY` (1-10): airy gallery vs. packed cockpit

**Baseline:** 8 / 6 / 4

**Golden rule:** Read the brief first. Never default to AI-purple gradients, centered hero, 3-equal-cards, or Inter font.
